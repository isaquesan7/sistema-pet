AINDA TEM DÚVIDAS?

Respostas para começar com confiança.

O PointVet foi pensado para simplificar — inclusive na hora de começar.

Preciso instalar alguma coisa? +

O PointVet possui interface web. Você acessa pelo navegador com internet e um usuário autorizado.

Posso cadastrar mais de uma unidade? +

A plataforma possui estrutura multiunidade. O número de unidades disponíveis depende dos limites do plano contratado.

O portal do cliente está incluído? +

O portal do tutor é um módulo do PointVet. Consulte os módulos incluídos em cada plano.

Posso experimentar antes de contratar? +

Alguns planos podem oferecer período de teste. A disponibilidade e a duração aparecem no catálogo de planos.
